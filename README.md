# VPN Config Checker

**Русский** · [English](README.en.md)

Проверяет бесплатные VPN-конфиги из открытых подписок прямо на телефоне и показывает, какие из них
работают сейчас в вашей сети. Мобильный интернет и Wi‑Fi считаются отдельно.

> Бесплатные конфиги живут недолго. Это чужие серверы, на них сидят тысячи человек, их блокируют,
> перегружают и убирают из списков. То, что работало вчера, сегодня может не подключиться.
> Своих серверов у приложения нет, оно только показывает, что из бесплатного работает у вас
> в данный момент. Перед использованием перепроверяйте.

## Зачем

Конфиги берутся из репозитория [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia):
несколько сотен ссылок VLESS, VMess, Trojan, Shadowsocks и Hysteria2, чёрные и белые списки, обновление
каждый час. Автор проверяет их со своего сервера, но у конкретного оператора картина другая, а перебирать
сотни ссылок руками в клиенте долго. Приложение перебирает их само и оставляет рабочие сверху.

Что ещё оно умеет:

- хранить результаты отдельно для мобильной сети и для Wi‑Fi и отмечать конфиги, которые работают в обеих;
- помечать конфиги из белых списков (серверы в белых подсетях российских хостеров) и на мобильной сети
  проверять их первыми;
- показывать для рабочего конфига страну, город, хостинг-провайдера и его сайт по внешнему IP;
- скачивать списки через любую сеть, в том числе через включённый VPN, а проверять потом на мобильном.

Это не VPN-клиент. Приложение ничего не туннелирует и не трогает настройки сети. Рабочие ссылки нужно
скопировать в свой обычный клиент: v2rayNG, Happ, Hiddify, NekoBox, Streisand или любой другой.

## Как пользоваться

1. Установите APK, откройте приложение, разрешите уведомления (в них идёт прогресс проверки).
2. Нажмите «Скачать конфиги».
3. Выберите вкладку «Мобильный» или «Wi‑Fi», подключитесь к этой сети, выключите VPN и нажмите
   «Проверить все». Фильтры «Рабочие», «Белые списки» и по протоколам сужают список, кнопка
   «Проверить показанные» проверяет только то, что отфильтровано.
4. Откройте рабочий конфиг и скопируйте ссылку в клиент. Кнопка «Поделиться» в шапке отдаёт
   все рабочие ссылки одним текстом.

Через день-другой повторите: часть конфигов умрёт, появятся новые.

## Как это работает

Для каждого конфига запускается отдельный процесс Xray-core или sing-box с локальным прокси, и через него
загружается api.2ip.io. Если ответ пришёл, конфиг считается рабочим, а из ответа берутся внешний IP, страна
и ASN. Hysteria2, Shadowsocks и конфиги с allowInsecure идут через sing-box, остальное через Xray.

Подписки скачиваются с нескольких зеркал одновременно, побеждает первое ответившее. Конфиги, которые
исчезли из списков и ни разу не работали, удаляются при следующем скачивании; рабочие остаются, пока не
провалят проверку. Нерабочие можно удалить руками через меню.

Провайдер определяется по внешнему IP: сначала ipwho.is, потом ip-api.com, потом встроенная таблица ASN.

Подробнее про устройство проекта: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Сборка

Нужны JDK 17 и Android SDK (platform 35, build-tools 35).

```bash
./scripts/fetch-cores.sh      # бинарники Xray-core и sing-box в jniLibs
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest
```

Релизы собирает GitHub Actions по тегу `v*`.

## Ограничения

- Только arm64: у Xray-core нет сборок под 32-битный ARM для Android.
- Не поддерживаются ssr://, tuic://, wireguard:// и Shadowsocks с плагинами.
- «Работает» значит, что 2ip.io открылся через конфиг. Скорость не измеряется.
- sing-box собран под 4 КБ страницы памяти и может не запуститься на Android 15 в режиме 16 КБ.

## Лицензии

[Xray-core](https://github.com/XTLS/Xray-core) (MPL-2.0) и [sing-box](https://github.com/SagerNet/sing-box)
(GPL-3.0) используются как отдельные процессы. Списки конфигов принадлежат их авторам и скачиваются
во время работы приложения.
